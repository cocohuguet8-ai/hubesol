## How to form the present perfect continuous

| Form | Structure | Example |
|---|---|---|
| Affirmative | subject + have/has + been + verb-**ing** | She **has been working**. / We**’ve been waiting**. |
| Negative | subject + haven’t/hasn’t + been + verb-ing | They **haven’t been sleeping**. |
| Question | Have/Has + subject + been + verb-ing? | **Have** you **been waiting** long? |

Use **have** with *I, you, we, they* and **has** with *he, she, it*. **Been** never changes, and the main verb always takes **-ing**. In a question with a question word, *have/has* comes next: *How long **have** you **been learning** English?*

**Short answers:** *Yes, I have. / No, she hasn’t.*

**Time expressions:** *for two hours, since Monday, all day, all morning, lately, recently, How long…?*

## Spelling of the -ing form

| Rule | Verb ending | Example |
|---|---|---|
| add -ing | most verbs | work → working, play → playing |
| drop -e, add -ing | verbs ending in *-e* | make → making, live → living |
| double the consonant | short verb, consonant–vowel–consonant | run → running, swim → swimming |
| -ie → -ying | verbs ending in *-ie* | lie → lying |

## When to use the present perfect continuous

### 1. How long, up to now

The activity started in the past and is still going on. Use *for* (a period) or *since* (a starting point).

- **I’ve been learning** English **for** five years.
- **She’s been living** here **since** 2019.

### 2. A recent activity with a result you can see now

The activity has just stopped (or nearly), and you can see the effect.

- My eyes hurt — **I’ve been reading** all day.
- The ground is wet. **It’s been raining.**

> ⚠️ Typical error: ✗ ~~You’ve run — you’re out of breath.~~ → ✓ **You’ve been running — you’re out of breath.** (The activity explains what you can see.)

### 3. Repeated actions over a period

An action that has happened again and again recently.

- **He’s been calling** me every day this week.

## For, since and How long

| Word | Position | Example |
|---|---|---|
| for + period | end of the sentence | I’ve been waiting **for an hour**. |
| since + point | end of the sentence | She’s been working **since nine**. |
| How long…? | start of the question | **How long** have you been studying? |
| all day / all morning | end of the sentence | They’ve been playing **all morning**. |
| lately / recently | end of the sentence | I’ve been sleeping badly **lately**. |

## State verbs

Verbs that describe a state, not an activity — *know, like, love, want, believe, own, belong* — do not use the continuous. Use the present perfect simple.

- ✗ ~~I’ve been knowing him for years.~~ → ✓ **I’ve known him for years.**

## Common mistakes

**1. Continuous for a finished quantity.** For a number or an amount, use the present perfect simple. ✗ *~~I’ve been reading three books.~~* → ✓ **I’ve read three books.**

**2. Continuous with a state verb.** ✗ *~~She’s been wanting a dog since May.~~* → ✓ **She’s wanted a dog since May.**

**3. Leaving out been.** The tense always needs *been*. ✗ *~~I have working all day.~~* → ✓ **I have been working all day.**

**Pro tip:** ask “Am I talking about the activity and how long it lasts?” If yes, use have/has been + -ing. If you are counting results, use the present perfect simple.
