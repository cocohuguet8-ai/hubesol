## The difference at a glance

| | Present Perfect | Present Perfect Continuous |
|---|---|---|
| Focus | the result / the finished action | the activity / its duration |
| Quantity | yes — I’ve read **three** books | no |
| How long | yes, with state verbs (I’ve known her for years) | yes, with action verbs (for / since) |
| Example | **I’ve painted** the door. | **I’ve been painting** all morning. |

The key question: are you counting a **result**, or describing the **activity**? A result or a number takes the simple; the ongoing activity or its duration takes the continuous.

## How to form them

| Form | Present Perfect | Present Perfect Continuous |
|---|---|---|
| Affirmative | have/has + past participle | have/has + been + verb-ing |
| | She**’s written** two emails. | She**’s been writing** emails. |
| Negative | haven’t/hasn’t + past participle | haven’t/hasn’t + been + verb-ing |
| | I **haven’t finished**. | I **haven’t been sleeping** well. |
| Question | Have/Has + subject + past participle? | Have/Has + subject + been + verb-ing? |
| | **Have** you **finished**? | **Have** you **been waiting** long? |

## When to use the present perfect (simple)

### 1. A finished result

The action is complete and the result matters now.

- **I’ve cleaned** the kitchen — it’s spotless.

### 2. How many / how much

Numbers and quantities need the simple form.

- **She’s sent** ten emails today.

> ⚠️ Typical error: ✗ ~~I’ve been reading three books this month.~~ → ✓ **I’ve read three books this month.** (*Three* is a quantity.)

## When to use the present perfect continuous

### 1. Duration up to now

- **I’ve been working** here for a year.
- **How long have** you **been waiting**?

### 2. A recent activity with a visible result

- **You’ve been crying** — your eyes are red.

## The same verb, two meanings

| Sentence | Meaning |
|---|---|
| I**’ve painted** the room. | It’s finished — come and look. |
| I**’ve been painting** the room. | That’s what I was doing (maybe not finished) — that’s why I’m covered in paint. |
| He**’s read** my report. | He has finished it. |
| He**’s been reading** my report. | He started it; maybe he hasn’t finished. |

## State verbs

*Know, have (= own), like, want, believe, belong* only use the simple form, even for how long.

- ✗ ~~I’ve been having this car for years.~~ → ✓ **I’ve had this car for years.**

## Common mistakes

**1. Continuous for a quantity.** ✗ *~~I’ve been writing five reports.~~* → ✓ **I’ve written five reports.**

**2. Simple when the point is how long the activity lasts.** ✗ *~~How long have you waited?~~* → ✓ **How long have you been waiting?**

**3. State verbs in the continuous.** ✗ *~~She’s been knowing him since 2015.~~* → ✓ **She’s known him since 2015.**

**Pro tip:** numbers and results → simple; how long and the activity itself → continuous; state verbs → always simple.
